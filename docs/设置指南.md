# Minis 设置指南 —— 在其他手机上复现

## 📱 第一步：安装 Minis

### iOS 设备
1. 打开 App Store
2. 搜索「Minis」
3. 下载安装（免费）

### 系统要求
- iOS 16.0 或更高版本
- 约 200MB 存储空间

---

## 🔧 第二步：初始配置

### 打开 Minis 后
1. 首次启动会引导你设置 AI 模型
2. 需要配置至少一个 AI 提供商（OpenAI / Anthropic / Gemini 等）
3. 在 [设置 → 模型提供商](minis://settings/providers) 中添加你的 API Key

### 推荐模型配置
- **主力模型**：Claude 3.5 Sonnet / GPT-4o
- **图像生成**：DALL-E 3 / Gemini（可选）
- **图像识别**：自带，无需额外配置

## 📦 第三步：安装技能包

### 方式一：手动复制（推荐）

将以下文件夹复制到新手机的 Minis 中：

```
/var/minis/skills/
├── social-media-login/    # 社交媒体后台数据抓取
│   └── SKILL.md
├── image-compression/     # 图片压缩技能
│   └── SKILL.md
└── skill-creator/         # 技能创建器（内置）
```

**复制步骤**：
1. 在旧手机上打开 Minis 终端
2. 运行 `ls /var/minis/skills/` 查看技能列表
3. 将技能文件夹通过 AirDrop / 微信文件传输助手 / iCloud Drive 传到新手机
4. 在新手机的 Minis 终端中，将文件放到 `/var/minis/skills/` 目录

## ⚠️ 注意事项

### 安全相关
- **验证码/人脸识别无法绕过**：这是平台安全措施，需手动完成
- **登录态会过期**：抖音约几小时，小红书约几天
- **不要频繁抓取**：避免被平台风控

### 存储相关
- 图片会占用会话体积，注意控制发图数量
- 定期清理 `/var/minis/attachments/uploads/`
- 使用 `python3 /root/bin/rz.py --all-known` 批量压缩

### 模型相关
- 确保 API Key 有足够额度
- 图像识别需要支持 vision 的模型
- 图像生成需要单独配置（可选）

## ❓ 常见问题

### Q: 为什么看不到技能？
A: 检查 `/var/minis/skills/` 目录是否存在，SKILL.md 文件是否完整。

### Q: 压缩脚本报错？
A: 确保已安装 `py3-pillow`：`apk add py3-pillow`

### Q: 登录时收不到验证码？
A: 小红书验证码有时会延迟，等一下再试。抖音验证码一般很快。

### Q: 会话还是超限了？
A: 图片已进入对话历史，压缩磁盘文件没用。必须新建对话。

### Q: 能在 Android 上用吗？
A: Minis 目前只有 iOS 版本。Android 用户可以考虑使用 Termux + 类似工具。

```python
#!/usr/bin/env python3
"""压图工具 —— 把上传的大图压到 1200px / JPEG q72

用法：
  python3 /root/bin/rz.py <文件名或路径> [...]
  python3 /root/bin/rz.py --all-known          # 压缩名单里所有已存在的文件
  python3 /root/bin/rz.py --check <名称...>     # 只看大小，不改

说明：
  默认在 /var/minis/attachments/uploads 下查找。
  同一个文件重复压不会变差（已小于 400KB 的直接跳过）。
"""
import os
import sys
from PIL import Image

D = "/var/minis/attachments/uploads"
MAX_PX = 1200
SKIP_BELOW = 400 * 1024  # 已经很小了就不动

def resolve(name):
    """返回实际存在的路径（支持给名字不带扩展名）"""
    if os.path.isabs(name) and os.path.exists(name):
        return name
    for cand in (name, os.path.join(D, name)):
        if os.path.exists(cand):
            return cand
    base = os.path.splitext(os.path.basename(name))[0]
    for ext in (".jpg", ".jpeg", ".png", ".webp", ".heic", ".JPG", ".PNG"):
        p = os.path.join(D, base + ext)
        if os.path.exists(p):
            return p
    return None

def compress(p):
    s0 = os.path.getsize(p)
    if s0 < SKIP_BELOW:
        print(f"  跳过（{s0//1024}KB < {SKIP_BELOW//1024}KB）：{p}")
        return
    img = Image.open(p)
    w, h = img.size
    if max(w, h) > MAX_PX:
        ratio = MAX_PX / max(w, h)
        img = img.resize((int(w*ratio), int(h*ratio)), Image.LANCZOS)
    if img.mode in ("RGBA", "P"):
        img = img.convert("RGB")
    out = os.path.splitext(p)[0] + ".jpg"
    img.save(out, "JPEG", quality=72, optimize=True)
    s1 = os.path.getsize(out)
    print(f"  {os.path.basename(p)}: {s0//1024}KB → {s1//1024}KB ({100-s1*100//s0}%)")

def main():
    args = sys.argv[1:]
    if not args:
        print("用法：rz.py <文件名...> | --all-known | --check <文件名...>")
        return
    if args[0] == "--check":
        for name in args[1:]:
            p = resolve(name)
            if p:
                print(f"  {name}: {os.path.getsize(p)//1024}KB")
            else:
                print(f"  {name}: 未找到")
        return

    main()
```

# Minis 快速开始

## 1️⃣ 安装 Minis
App Store 搜索「Minis」→ 下载安装

## 2️⃣ 配置 AI 模型
打开 Minis → 设置 → 模型提供商 → 添加你的 API Key

## 3️⃣ 安装技能
在 Minis 终端中运行：
```bash
# 安装 Python 和图片处理
apk update && apk add python3 py3-pillow

# 创建技能目录
mkdir -p /var/minis/skills/

# 下载技能（替换为实际地址）
cd /var/minis/skills/
git clone https://github.com/your-username/minis-skills.git

# 下载压缩脚本
mkdir -p /root/bin/
curl -o /root/bin/rz.py https://raw.githubusercontent.com/your-username/minis-skills/main/rz.py
chmod +x /root/bin/rz.py
```

## 4️⃣ 测试功能
在 Minis 对话中说：
- 「登录抖音」→ 自动打开创作者中心
- 「压缩图片」→ 自动压缩大图
- 「查看后台数据」→ 抓取并分析数据
